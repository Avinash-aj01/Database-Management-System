# Database Management System
**ER Model-**
Entity-relationship model is illustrated with an example of an E-Commerce platform.
The image consists of a structured schema of **entities**, their **attributes** and the **relationships** between them.
It includes **Primary Keys** which are **NOT NULL** and **unique**. Moreover,**multi-valued attributes** to give a detailed explanation to the nature of the attribute.

**Relational Schema-**
Converting the ER Model into a relational schema using **MySQL**. The file contains SQL query implementing various table creations that follow necessary constraints to verify data integrity.
